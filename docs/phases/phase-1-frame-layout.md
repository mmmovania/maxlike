# Phase 1 — Frame layout

Branch: `phase/1-frame-layout`

Acceptance criteria: see `docs/spec/02-plan.md`, Phase 1.

## Steps
- [x] **1.1 Layout skeleton**: `ComputeFrameLayout` (pure, unit-tested), seven placeholder
      region windows, bevel helpers, font handed to children with `WM_SETFONT`
- [x] **1.2 Menu bar**: menus as data (`MenuSpec`), `CommandTable` name↔ID, `BuildMenuBar`,
      `WM_COMMAND` dispatch by name; tests in `tests/test_menu_spec.cpp`
- [x] **1.3 Tab panel**: custom-drawn `TabPanel`, geometry in `TabStrip` (unit-tested);
      matches the reference pixel for pixel apart from label text
- [x] **1.4a Main toolbar: buttons and layout**: `ToolbarSpec` (data + layout, unit-tested),
      custom-drawn `Toolbar` with hover, press, radio groups and flyout markers; original
      placeholder icons generated by `tools/make_icons.py`
- [x] **1.4b Main toolbar: tooltips and combo boxes**: native classic `COMBOBOX` children
      with R3's entries; a tooltip control for every button and combo
- [x] **1.4c Main toolbar: flyouts**: press-and-hold opens a `FlyoutStrip` popup; drag and
      release picks an alternative, which becomes the button's face and runs its command
- [x] **1.5a Time slider and track bar**: custom-drawn `TimeSlider` (drag, arrows with
      auto-repeat, click-to-jump) and `TrackBar`; geometry in `TimeSliderGeometry` (unit-tested)
- [x] **1.5b Status area, left**: `StatusBar` with the MAXScript mini-listener (two real
      EDIT controls), draggable splitter, prompt lines, selection lock, X/Y/Z and grid
      fields; layout in `StatusLayout` (unit-tested)
- [x] **1.5c Status area, right**: `Toolbar` made config-driven (`toolbar::Config`) and
      reused for two status groups: toggles/snaps, and Animate/playback/key mode/frame
      field/navigation; 29 original 16-px icons; Time Tag tooltip; playback buttons and the
      frame field drive the time slider
- [ ] 1.6 Overlay check against the reference screenshot

## Notes
- Measurements are client-relative at 100%: client top = bottom of the menu bar
  (screen y 42 in the reference), client size 1920×998.
- Viewport borders are more intricate than the spec's "two rings": between viewports the
  reference shows `C0 | FF FF | 00 C0`, the outer top is `A0 FF FF C0`, the bottom
  `C0 00 00`. Re-measure per viewport in Phase 2.
- The command panel edge is exactly `DrawEdge(EDGE_RAISED)` with system colours
  (`FFFFFF/E3E3E3` top-left, `A0A0A0/696969` bottom-right).
